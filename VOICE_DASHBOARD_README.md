# Voice Channels Dashboard System

## Обзор

Эта система интегрирует Discord бота с Telegram ботом для отслеживания активности в голосовых каналах Discord и отображения информации в реальном времени в Telegram.

## Функциональность

### Discord Bot
- Отслеживает изменения в голосовых каналах (присоединение, выход, переключение)
- Сохраняет информацию о пользователях в базе данных
- Автоматически обновляет дашборды в Telegram

### Telegram Bot
- Создание дашбордов с информацией о голосовых каналах
- Автоматическое обновление дашбордов при изменениях
- Управление дашбордами (создание, удаление, обновление)
- Статистика по голосовым каналам

## Команды Telegram бота

### Основные команды
- `/help` - Показать все доступные команды
- `/create_dashboard` - Создать новый дашборд голосовых каналов
- `/update_dashboards` - Принудительно обновить все дашборды
- `/list_dashboards` - Показать все активные дашборды в чате

### Управление дашбордами
- `/remove_dashboard` - Удалить дашборд (ответить на сообщение с дашбордом)

### Статистика и администрирование
- `/voice_stats` - Показать детальную статистику по голосовым каналам
- `/clear_voice_channels` - Очистить все записи о пользователях в голосовых каналах (админ)

## База данных

### Новые таблицы

#### `voice_channel_users`
Хранит информацию о пользователях, находящихся в голосовых каналах:
- `id` - Автоинкрементный ID
- `user_id` - ID пользователя Discord
- `user_name` - Имя пользователя Discord
- `display_name` - Отображаемое имя пользователя
- `channel_id` - ID голосового канала
- `channel_name` - Название голосового канала
- `joined_at` - Время присоединения к каналу

#### `dashboards`
Хранит информацию об активных дашбордах:
- `id` - Автоинкрементный ID
- `chat_id` - ID чата Telegram
- `message_id` - ID сообщения с дашбордом
- `created_at` - Время создания
- `updated_at` - Время последнего обновления

## Логика работы

### Discord Events
1. Когда пользователь присоединяется к голосовому каналу:
   - Создается/обновляется запись в `discord_users`
   - Добавляется запись в `voice_channel_users`
   - Отправляется уведомление в Telegram
   - Обновляются все дашборды

2. Когда пользователь покидает голосовой канал:
   - Удаляется запись из `voice_channel_users`
   - Отправляется уведомление в Telegram
   - Обновляются все дашборды

3. Когда пользователь переключается между каналами:
   - Обновляется запись в `voice_channel_users`
   - Отправляется уведомление в Telegram
   - Обновляются все дашборды

### Dashboard Updates
- Автоматически обновляются при изменениях в голосовых каналах
- Можно принудительно обновить командой `/update_dashboards`
- Показывают текущих пользователей по каналам
- Отображают общее количество пользователей онлайн

## Использование

1. Запустите оба бота (Discord и Telegram)
2. В Telegram чате используйте `/create_dashboard` для создания дашборда
3. Дашборд будет автоматически обновляться при изменениях в Discord голосовых каналах
4. Используйте другие команды для управления и мониторинга

## Особенности

- Поддержка множественных дашбордов в разных чатах
- Автоматическая очистка несуществующих дашбордов
- Детальная статистика по голосовым каналам
- Логирование всех действий
