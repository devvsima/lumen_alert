# Команды бота

## Telegram

### Основные команды

| Команда | Назначение |
|---|---|
| `/start` | Запуск бота |
| `/help` | Показать справку |
| `/lang` | Выбрать язык |
| `/language` | Выбрать язык |
| `/invite` | Показать реферальную информацию |
| `/settings` | Настроить типы уведомлений |
| `/sources` | Выбрать Discord-серверы и голосовые каналы для уведомлений |

### Дашборды

| Команда | Назначение |
|---|---|
| `/create_dashboard` | Создать дашборд текущего чата |
| `/update_dashboards` | Принудительно обновить все дашборды |
| `/remove_dashboard` | Удалить дашборд. Команду нужно отправить ответом на сообщение дашборда |
| `/list_dashboards` | Показать дашборд текущего чата |

Для одного Telegram-чата используется только один дашборд. При создании нового предыдущий дашборд удаляется.

### Статистика голосовых каналов

| Команда | Назначение |
|---|---|
| `/voice_stats` | Показать текущую статистику голосовых каналов |
| `/clear_voice_channels` | Очистить записи о пользователях в голосовых каналах и обновить дашборды |

### Администрирование Telegram

| Команда | Доступ |
|---|---|
| `/admin` | Администраторы Telegram |

## Discord

| Команда | Назначение | Доступ |
|---|---|---|
| `/notification-channels` | Разрешить или запретить голосовые каналы для уведомлений | Администраторы Discord-сервера |
| `/ignore-bots` | Включить или выключить уведомления от Discord-ботов | Администраторы Discord-сервера |
| `/notification-messages` | Изменить шаблоны сообщений о входе, выходе и переходе между каналами | Администраторы Discord-сервера |
| `/notification-link` | Получить ссылку для подключения сервера в Telegram | Администраторы Discord-сервера |

Ссылка из `/notification-link` открывает Telegram-бота и автоматически подключает
пользователя ко всем разрешённым голосовым каналам этого Discord-сервера. Повторное
открытие ссылки не создаёт дубликатов подписок.

### Управление каналами

- `✅` — канал разрешён для подписки и уведомлений.
- `🚫` — канал запрещён для подписки и уведомлений.
- Запрещённый канал не отображается пользователям Telegram.
- Уведомления и данные запрещённого канала не попадают в дашборды.

### Шаблоны уведомлений

Доступные переменные:

```text
{user}
{channel}
{from_channel}
{server}
```

Пример:

```text
{user} вошёл в канал «{channel}»
```
